## ✅ À SAVOIR

**Vos clients n'ont RIEN à faire!**
- Ils téléchargent juste TradabotConnector.exe
- Ils double-cliquent dessus
- C'est tout!

**VOUS compilez UNE FOIS:**
- Sur votre PC Windows
- Vous obtenez TradabotConnector.exe
- Vous le mettez sur le site
- Tout le monde télécharge ce même fichier

---

## 🎯 COMPILATION EN 3 CLICS

### ÉTAPE 1: Télécharger le dossier tradabot-connector

1. Téléchargez le dossier **tradabot-connector** depuis votre serveur
2. Mettez-le sur votre **Bureau** ou dans **Documents**

### ÉTAPE 2: Double-cliquer sur BUILD_CONNECTOR.bat

1. Ouvrez le dossier **tradabot-connector**
2. Trouvez le fichier **BUILD_CONNECTOR.bat**
3. **Double-cliquez** dessus
4. Si Windows demande → Cliquez **"Oui"**
5. Une fenêtre bleue s'ouvre
6. Appuyez sur **Entrée** pour commencer
7. **ATTENDEZ 5-10 MINUTES** ⏱️
8. À la fin, vous verrez:
   ```
   ✅ COMPILATION TERMINÉE!
   📦 Le fichier est ici: dist\TradabotConnector.exe
   ```

### ÉTAPE 3: Récupérer le .exe

1. Dans le dossier **tradabot-connector**
2. Ouvrez le dossier **dist**
3. Vous verrez **TradabotConnector.exe** (2-3 MB)
4. ✅ **C'est celui-ci que vos clients téléchargeront!**

---

## 📤 METTRE LE .EXE SUR LE SITE

### Option 1: Via l'interface Emergent

1. Uploadez **TradabotConnector.exe** dans `/app/tradabot-connector/`
2. Redéployez le site
3. ✅ Les clients pourront le télécharger!

### Option 2: Via FTP/SFTP

Si vous avez accès SFTP:
1. Connectez-vous au serveur
2. Uploadez **TradabotConnector.exe** dans `/app/tradabot-connector/`
3. ✅ Disponible immédiatement!

## 🧪 TESTER LE .EXE

Avant de le mettre sur le site:

1. **Double-cliquez** sur TradabotConnector.exe
2. Il devrait vous demander:
   ```
   === TRADABOT CONNECTEUR ===
   
   Connexion à votre compte Tradalife...
   Email:
   ```
3. Entrez votre email tradalife.com
4. Entrez votre mot de passe
5. Il devrait se connecter et afficher:
   ```
   ✅ Connexion réussie!
   ✅ Configuration chargée
   Connexion à MT4...
   ```
6. ✅ Si ça marche → C'est prêt pour vos clients!
