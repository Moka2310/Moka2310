# 🎯 INSTALLATION EN 3 CLICS - TRADABOT

## ⚠️ AVANT DE COMMENCER

### Vous avez besoin de:
1. **Windows 10 ou 11**
2. **Python 3.11** installé (gratuit - voir ci-dessous si pas fait)
3. **MetaTrader 4 ou 5** installé (gratuit - voir ci-dessous)

---

## 🔴 ÉTAPE 0: Installer Python (Si pas déjà fait)

### Comment savoir si Python est installé?
1. Appuyez sur `Windows + R`
2. Tapez: `cmd`
3. Appuyez sur Entrée
4. Dans la fenêtre noire, tapez: `python --version`
5. Si vous voyez `Python 3.11.x` → ✅ **C'est bon, passez à l'ÉTAPE 1**
6. Si vous voyez une erreur → ❌ **Suivez les instructions ci-dessous**

### Installer Python (5 minutes):
1. Allez sur: https://www.python.org/downloads/
2. Cliquez sur le gros bouton jaune "Download Python 3.11.x"
3. Le fichier se télécharge
4. **Double-cliquez** sur le fichier téléchargé
5. ⚠️ **TRÈS IMPORTANT:** COCHEZ la case **"Add Python to PATH"** (tout en bas)
6. Cliquez sur "Install Now"
7. Attendez 2-3 minutes
8. Cliquez sur "Close"
9. ✅ **Python est installé!**

---

## 🔴 ÉTAPE 1: Extraire le ZIP

1. Allez dans votre dossier "Téléchargements"
2. Trouvez le fichier **TRADABOT_Package.zip**
3. **Clic droit** dessus
4. Choisir **"Extraire tout..."**
5. Choisir un emplacement simple, par exemple: **C:\TRADABOT\**
6. Cliquer sur **"Extraire"**
7. Un dossier **tradabot-app** apparaît
8. ✅ **Fichiers extraits!**

---

## 🔴 ÉTAPE 2: Lancer l'installation automatique

1. Ouvrez le dossier **tradabot-app** (celui que vous venez d'extraire)
2. Trouvez le fichier **INSTALL_AUTO.bat**
3. **Double-cliquez** dessus
4. ⚠️ Si Windows demande: "Voulez-vous autoriser...?" → Cliquez **"Oui"**
5. Une fenêtre noire s'ouvre avec du texte vert
6. Appuyez sur **"Entrée"** quand demandé
7. **ATTENDEZ 15-20 MINUTES** ⏱️
   - Ne fermez PAS la fenêtre!
   - Vous allez voir plein de texte défiler
   - C'est NORMAL!
8. À la fin, vous verrez:
   ```
   ✅ INSTALLATION TERMINÉE!
   ```
9. Le script vous demande: "Voulez-vous lancer TRADABOT maintenant?"
10. Tapez **O** (pour Oui) et appuyez sur **Entrée**
11. ✅ **TRADABOT se lance!**

---

## 🔴 ÉTAPE 3: Utiliser TRADABOT

### Première fois:
1. L'application TRADABOT s'ouvre
2. Vous voyez plusieurs onglets: Connexion, Configuration, Signaux, etc.

### Onglet "Connexion":
1. **Email:** Votre email tradalife.com (ex: votre@email.com)
2. **Mot de passe:** Votre mot de passe tradalife
3. Cliquez sur **"SE CONNECTER"**
4. ✅ Vous devriez voir: "Connexion réussie"

### Onglet "Configuration":
1. **Login MT4:** Votre numéro de compte MT4 (ex: 12345678)
2. **Password MT4:** Votre mot de passe MT4
3. **Server:** Sélectionnez dans la liste (ex: XM.COM-Demo, ICMarkets-Live, etc.)
   - Vous pouvez taper pour chercher
   - Si votre serveur n'est pas listé, choisissez "Saisir manuellement"
4. Cliquez sur **"CONNECTER MT4"**
5. ✅ Vous devriez voir: "Connecté à MT4"

### Activer les canaux:
1. Cochez les canaux que vous voulez (Forex, Crypto, Gold, etc.)
2. Définissez les lots (ex: 0.01 pour commencer)
3. Cliquez sur **"Sauvegarder Configuration"**

### Démarrer le bot:
1. Cliquez sur le gros bouton vert: **"▶️ DÉMARRER LE BOT"**
2. ✅ En haut à droite, vous verrez: **"🟢 Bot Actif"**
3. Dans l'onglet "Logs", vous verrez: **"🚀 BOT DÉMARRÉ"**

## ❓ PROBLÈMES FRÉQUENTS

### Problème 1: "Python n'est pas reconnu"
**Solution:** Vous avez oublié de cocher "Add Python to PATH". Désinstallez Python et réinstallez en cochant la case!

### Problème 2: L'installation bloque
**Solution:** Attendez! Ça peut prendre 15-20 minutes. Tant que la fenêtre ne se ferme pas, c'est que ça marche.

### Problème 3: "Échec connexion MT4"
**Solution:** 
- Vérifiez que MetaTrader 5 est bien installé
- Vérifiez votre Login (c'est un numéro)
- Vérifiez votre mot de passe
- Vérifiez le nom EXACT du serveur (dans MT4 → Outils → Options → Serveur)

### Problème 4: Pas de fichier INSTALL_AUTO.bat
**Solution:** Vous avez peut-être oublié d'extraire le ZIP. Faites un clic droit sur TRADABOT_Package.zip → "Extraire tout"
