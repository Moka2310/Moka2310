## 📥 COMMENT L'UTILISER

### 1️⃣ TÉLÉCHARGER LE NOUVEAU CONNECTEUR
1. Allez sur **https://tradalife.com/tradabot-web**
2. Cliquez sur **"📥 Télécharger le Connecteur"**
3. Un fichier `TRADABOT_CONNECTOR.zip` (7 KB) sera téléchargé

### 2️⃣ INSTALLER
1. **Extrayez** le fichier ZIP dans un dossier (ex: `C:\TRADABOT`)
2. **Double-cliquez** sur `INSTALLATION_SIMPLE.bat`
3. Suivez les instructions (le script installe tout automatiquement)

**Si Python n'est pas installé:**
- Le script ouvrira automatiquement la page de téléchargement
- ⚠️ **IMPORTANT**: Cochez "Add Python to PATH"
- Redémarrez votre PC après installation
- Relancez `INSTALLATION_SIMPLE.bat`

### 3️⃣ CONFIGURER
1. Retournez sur **https://tradalife.com/tradabot-web**
2. Allez dans l'onglet **"⚙️ Configuration"**
3. Remplissez vos paramètres MT4/MT5:
   - Login
   - Mot de passe  
   - Serveur (ex: ICMarkets-Live)
   - Canaux actifs (Forex, Crypto, Gold, etc.)
   - Tailles de lots
4. Cliquez sur **"💾 Sauvegarder la Configuration"**
5. Cliquez sur **"📥 Télécharger tradabot_config.json"**
6. **Placez ce fichier** dans le dossier `C:\TRADABOT`

### 4️⃣ LANCER
1. **Ouvrez MetaTrader 4 ou 5** et connectez-vous
2. **Double-cliquez** sur `DEMARRER_TRADABOT.bat`
3. Vous verrez:

## 🆘 EN CAS DE PROBLÈME

### Le script se ferme immédiatement?
- Ouvrez l'Invite de commandes (CMD)
- Allez dans le dossier: `cd C:\TRADABOT`
- Tapez: `python tradabot_simple.py`
- Vous verrez l'erreur exacte qui sera expliquée clairement

### Python n'est pas installé?
1. Téléchargez: https://www.python.org/downloads/
2. Installez en cochant **"Add Python to PATH"**
3. Redémarrez votre PC
4. Relancez `INSTALLATION_SIMPLE.bat`

### Configuration manquante?
- Téléchargez `tradabot_config.json` depuis le site
- Placez-le dans le dossier TRADABOT

### Connexion MT5 échoue?
- Vérifiez que MetaTrader est OUVERT
- Vérifiez vos identifiants dans la configuration web
- Le serveur doit être exactement le bon (ex: ICMarkets-Live)
